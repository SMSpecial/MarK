## 📌 نبذة عن المشروع (About The Project)

الموقع الرسمي والتفاعلي لمؤسسة **العلامة المميزة (Special MarK Tech)**. صُمم الموقع بأعلى درجات الفخامة والأناقة التقنية (Royal Gold & Dark Obsidian) ليخدم الشركات، رواد الأعمال، والمؤسسات الباحثة عن التميز والابتكار في العالم الرقمي.

المستودع الرسمي على GitHub:  
👉 **[https://github.com/SMSpecial/MarK](https://github.com/SMSpecial/MarK)**

رابط النشر التلقائي عبر GitHub Pages:  
👉 **[https://SMSpecial.github.io/MarK/](https://SMSpecial.github.io/MarK/)**

## 💎 أبرز المزايا والأنظمة المدمجة (Key Features)

1. **مصفوفة الأفكار التفاعلية (Vision Architect Matrix):**
   - أداة متطورة تمكّن الزائر من اختيار مجاله (FinTech، متاجر فاخرة، عقارات، صحة، تعليم، لوجستيات) وتوليد مخطط هيكلي معماري فوري وحزمة برمجيات موصى بها مع جدول مراحل العمل (Milestones).
2. **حاسبة نطاق وتكلفة المشاريع (Interactive Scoping & Cost Estimator):**
   - حاسبة ذكية بالدولار والدينار الأردني لتقدير تكاليف المنصات والتطبيقات والهويات والمدة الزمنية بدقة وشفافية.
3. **درع الأمان السيبراني الشامل (Enterprise Security & Defense):**
   - استعراض مواصفات التشفير العسكري (AES-256 & TLS 1.3)، اتفاقيات عدم الإفصاح (NDA)، تحصين OWASP Top 10، فاحص الجاهزية الأمنية التفاعلي.
4. **معرض المشاريع البارزة وحالات النجاح (Case Studies & Portfolio):**
   - تصفية المشاريع بحسب النوع، واستعراض تفاصيل التحدي والحل الهندسي والنتائج، مع ربط مباشر بمجلد العروض السحابي على Google Drive.
5. **نظام حجز الاستشارات التقنية الفوري:**
   - نموذج تفاعلي لتحديد موعد الجلسة (حضوري في شارع وصفي التل أو عبر Google Meet أو هاتفياً) مع إصدار تذكرة كود VIP مشفرة ومحادثة واتساب مسبقة الصياغة.
6. **ثنائية اللغة ودعم الاتجاهات (Bilingual Arabic / English & RTL/LTR):**
   - دعم متكامل للغة العربية والإنجليزية، مع تبديل النمط الليلي الفاخر والنهاري.

## 🛠 حزمة التقنيات المستخدمة (Tech Stack)

- **Frontend Core:** React 19, TypeScript
- **Bundler & Tooling:** Vite 8
- **Styling & Theme:** Tailwind CSS v4, Lucide React Icons
- **Deployment:** GitHub Pages (Static Hosting) & Google Cloud Run (Full-Stack Docker Ready)

---

## ☁️ منظومة التزامن السحابي المباشر (Direct Cloud Architecture)

المشروع مصمم ليعمل بمنظومة سحابية متكاملة ومستقلة تماماً عن أي أجهزة أو بيئات محلية، وتتم إدارته عبر ركيزتين:
1. **Google AI Studio / Cloud Run:** لإدارة الشيفرة البرمجية، المعاينة الحية الفورية، وتشغيل خادم البوابة الهندسية عالي الأداء مع طبقات الأمان السيبراني.
2. **GitHub Repository (`SMSpecial/MarK`):** لإدارة النسخ البرمجية، وأتمتة البناء والنشر الفوري إلى **GitHub Pages** عبر مسار CI/CD المؤتمت (`npm ci`).

## 🚀 التشغيل والتطوير (Development & Cloud Run)

### 1. استنساخ المستودع (Clone):
```bash
git clone https://github.com/SMSpecial/MarK.git
cd MarK
```

### 2. تثبيت الحزم (Install Dependencies):
```bash
npm install
```

### 3. تشغيل خادم التطوير السريع (Start Dev Server):
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

---

## 📦 أوامر البناء والنشر (Build & Deploy Scripts)

| الأمر | الوصف |
| :--- | :--- |
| `npm run dev` | تشغيل خادم التطوير المحلي على المنفذ 3000 |
| `npm run build` | بناء المشروع للإنتاج القياسي |
| `npm run build:gh-pages` | بناء المشروع خصيصاً لمستودع `https://SMSpecial.github.io/MarK/` |
| `npm run preview` | معاينة حزمة الإنتاج محلياً على المنفذ 3000 |
| `npm run lint` | فحص الشيفرة البرمجية والأنماط عبر TypeScript (`tsc --noEmit`) |

## 🌐 النشر على GitHub Pages (Deploy to GitHub Pages)

المشروع يحتوي بالفعل على مسار عمل مؤتمت كامل داخل:  
`.github/workflows/deploy.yml`

### خطوات التفعيل في المستودع:
1. افتح مستودعك: `https://github.com/SMSpecial/MarK`
2. اضغط على **Settings** > **Pages** (في القائمة الجانبية).
3. تحت قسم **Build and deployment**:
   - في خانة **Source** اختر: **GitHub Actions**.
4. بمجرد رفع أي تحديث (`git push`) لفرع `main`، سيعمل مسار العمل تلقائياً ويتم النشر على:  
   👉 **https://SMSpecial.github.io/MarK/**

## 🔒 الأمان وحماية البيانات (Security & Privacy)

- تم فحص كود الواجهة بالكامل: **خالٍ 100% من أي مفاتيح API أو أسرار أو بيانات اعتماد مشفرة**.
- ملف `.gitignore` محصن ويستثني كافة ملفات `.env*` والمفاتيح المحلية والملفات المؤقتة.
- تم تزويد الموقع بملف `404.html` لدعم استعادة مسارات الـ SPA على GitHub Pages بدون أي شاشات خطأ.
